# 중고차 꿀매물 분석기

제조사·모델·연식·가격 조건을 고르면 중고차 매물의 시세·보험이력·성능점검을 분석해
S~F 등급과 추천 이유, 사고 부위 도면을 보여주는 웹사이트입니다.

- 서버 없이 방문자 브라우저에서 모든 수집·분석이 실행됩니다 (`index.html` + `app.js`).
- 요청은 1~2초 간격으로 보내며, 받은 데이터와 가격 이력은 브라우저(IndexedDB)에 캐시됩니다.
- 점수: 가격 적정성 35 · 이력 30 · 상태 25 · 주행거리 10 = 100점. 침수·전손·도난·주요골격 손상은 F(제외), 보험 정보제공 불가 기간 3개월 이상은 최대 C.
- 휴대폰 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.

비공식 개인 프로젝트이며 엔카(encar.com)와 관련이 없습니다. 분석 결과는 참고용입니다.
